# Ricky Fort Merch

Proyecto de integración de la materia Intro al desarrollo de software (cátedra Camejo).

## Cómo probar la API (Bruno)

Con el backend levantado (`npm run dev` en `backend/`), abrí Bruno, elegí **Open Collection** y seleccioná la carpeta `backend/bruno`. Arriba a la derecha, elegí el entorno **local**. Ahí están los pedidos para listar, ver, crear, editar y eliminar productos, y uno de **Crear producto con error** (manda un precio negativo para ver el `400`).
